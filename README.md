# JBR Development - Portfolio

Portfolio professionnel de Jean-Baptiste Renart, développeur web freelance.

## Stack technique

- **Framework** : Next.js 16
- **Styling** : Tailwind CSS v4
- **Typo** : Space Grotesk
- **i18n** : next-intl (FR/EN)
- **Déploiement** : Vercel

## Développement

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
```
