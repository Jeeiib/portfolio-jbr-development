# Calendrier éditorial /conseils

Backlog priorisé pour la routine hebdomadaire. Un sujet par semaine, pris **dans l'ordre**, le premier non coché. Cocher le sujet dans le même commit que l'article.

Règles de rédaction, non négociables : minimum 800 mots utiles, structure en H2 (au moins 4, pour que le sommaire s'affiche), maillage vers `/tarifs` et `/brief`, ancrage local Lille et métropole, aucun fait ni chiffre inventé. Les chiffres autorisés sans source externe sont ceux du dépôt : segments de marché de `tarifs.compare`, grille 1 190 / 3 900 / 79 € HT, délais 2-3 semaines (vitrine) et 4-8 semaines (sur-mesure), réponse sous 24 h, devis sous 48 h.

## À traiter, dans cet ordre

- [ ] **Site internet pour expert-comptable : ce qui change vraiment**
  Intention : « site internet cabinet comptable ». Angle : la confiance et la prise de rendez-vous plutôt que la vitrine ; le passage du site à l'outil métier. S'appuyer sur ce qui est déjà public de REV Comptabilité, sans rien ajouter. Maillage : /services/application-web-sur-mesure, /brief.

- [ ] **Être trouvé quand on est artisan : les trois leviers qui comptent**
  Intention : « référencement local artisan Lille ». Angle : fiche Google, pages par commune desservie, avis. Distinguer ce qui est gratuit de ce qui demande un site. Maillage : /conseils/fiche-google-business-tpe-10-minutes, /tarifs.

- [ ] **Combien de temps prend la création d'un site, réellement**
  Intention : « délai création site internet ». Angle : le planning honnête, et le fait que le délai dépend surtout du client (contenus, validations). Utiliser les délais affichés. Maillage : /tarifs, /brief.

- [ ] **Refonte ou nouveau site : comment ne pas perdre son référencement**
  Intention : « refonte site sans perdre référencement ». Angle : ce qu'il faut préserver (URL, redirections, contenus qui performent) et le risque concret d'une migration bâclée. Maillage : /tarifs, /brief.

- [ ] **Ce qu'un site coûte après la mise en ligne**
  Intention : « coût maintenance site internet ». Angle : hébergement, nom de domaine, mises à jour, sécurité ; ce qui est inclus et ce qui ne l'est pas. Maillage : /tarifs, /brief.

- [ ] **Préparer un brief efficace : ce que votre prestataire a besoin de savoir**
  Intention : « comment rédiger un cahier des charges site web ». Angle : les six questions qui font gagner deux semaines, et pourquoi un brief précis fait baisser le devis. Maillage : /brief en premier.

- [ ] **Votre site est-il vraiment sécurisé ? Le minimum vital**
  Intention : « sécurité site internet TPE ». Angle : HTTPS, sauvegardes, mises à jour, RGPD de base, et le risque réel pour une petite structure. Maillage : /tarifs, /brief.

- [ ] **Site vitrine ou boutique en ligne : la bonne question à se poser**
  Intention : « site vitrine ou e-commerce ». Angle : le coût caché du e-commerce (logistique, paiements, retours) contre la simplicité d'un site qui fait décrocher le téléphone. Maillage : /tarifs, /brief.

- [ ] **Pourquoi votre concurrent passe devant vous sur Google**
  Intention : « pourquoi mon concurrent est mieux référencé ». Angle : les vrais facteurs (fiche, citations locales, contenu, technique) et ce qui n'en est pas un. Rappeler que les scores d'outils tiers ne sont pas des signaux Google. Maillage : /conseils, /brief.

- [ ] **Un outil métier plutôt qu'un site : quand ça devient rentable**
  Intention : « application web sur mesure PME ». Angle : le calcul en heures gagnées par mois plutôt qu'en prix de projet. Maillage : /services/application-web-sur-mesure, /tarifs.

## Quand le backlog est vide

La routine n'invente pas de sujet à la volée : elle ouvre une PR qui propose quatre nouveaux sujets à ajouter ici, tirés des requêtes en hausse dans Search Console (voir la boucle mensuelle dans `ops-seo-local.md`).
